This note is a summary of a-lvl computing syllabus. 


# Topics

## 🧠 Foundations

- [[Data Representation]]: Convert between binary, denary, and hexadecimal.
- [[Encoding]]: Understand ASCII, Unicode, and their trade-offs.
- [[Program Memory Allocation]]: Review code, data, BSS, heap, and stack segments.
- [[Data Validation and Verification]]: Compare validation and verification, program errors, and test data.
- [[Ethics]]: Explore professional responsibilities, legislation, and computing ethics.


## ⚙️ Programming Concepts

- [[Algorithm, Pesudocode, Flowchart and Decision Table|Algorithms, Pseudocode, Flowcharts & Decision Tables]]: Plan solutions using pseudocode, flowcharts, and decision tables.
- [[Modularisation]]: Use functions, procedures, parameters, and variable scope.
- [[Recursion]]: Understand recursive calls, stack frames, benefits, and limitations.
- [[OOP|Object-Oriented Programming]]: Review class diagrams, terminology, and the four pillars of OOP.
- [[Misc|Python Toolkit]]: Revise dictionaries, datetime, CSV handling, and randomisation.


## 🔎 Algorithms

- [[Searching Algorithm|Searching Algorithms]]: Linear search, binary search, hashing, and collision handling.
- [[Sorting Algorithm|Sorting Algorithms]]: Bubble, insertion, quick, and merge sort.



## 🧱 Files & Data Structures

- [[File|Files]]: Serial and sequential files, plus absolute and relative paths.
- [[Stack|Stacks]]: LIFO behaviour and core stack operations.
- [[Queue|Queues]]: Linear, circular, and priority queues.
- [[Linked List|Linked Lists]]: Node deletion, free-space lists, and ordered insertion.
- [[Tree|Trees]]: Tree terminology, traversals, and binary search trees.


## 🗃️ Data & Databases

- [[Data Management]]: Data lifecycle, integrity, security, backups, archives, version control, and PDPA.
- [[Relational Databases]]: SQL queries, ER diagrams, keys, dependencies, and normalisation.
- [[Non-relational Database|Non-relational Databases]]: NoSQL terminology, CRUD, ACID, applications, and syntax.


## 🌐 Networks & Web

- [[Computer Network|Computer Networks]]: Network types, topologies, hardware, protocols, and devices.
- [[Network Security]]: Social engineering, malware, firewalls, DoS attacks, IDS, and IPS.
- [[Web Applications]]: Native versus web apps, usability principles, CSS, Flask, and Jinja2.
