# Data Validation

| Validation Check                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Example                                                                                                                             |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Presence check**               | Check that the data is actually present, i.e. not left blank/missed out.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Input data is not empty.                                                                                                            |
| **Type check**                   | Check whether data is of correct data type.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Input data must be an integer.                                                                                                      |
| **Existence check**              | Identifies whether a certain value is present in a specified area.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | SubType must have the value `A` or `P`.                                                                                             |
| **Length check**                 | Checks if the input data contains a specified number of characters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Input data must have 4 characters.                                                                                                  |
| **Range check**                  | Checks if the input value is within a certain range.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `1 <= x <= 10`                                                                                                                      |
| **Format check / Picture check** | Check whether the input data matches a predetermined pattern and that particular characters have particular values such as being letters or digits.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Input data must be in this format: `DD-MM-YYYY`.                                                                                    |
| **Check Digit**                  | A check digit is an extra digit added to a number which is calculated from the pre-existing digits. The computer re-calculates and validates/invalidates the check digit.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `31245142(6)`, where `(6)` is the check digit calculated from the other digits.                                                     |
| **Integrity check**              | To confirm the value of a piece of data by comparing it with other data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Input data 1: Date of birth, Input data 2: Age, if Input data 1 does not match with Input data 2, then the input will not be valid. |
| **Lookup checks**                | Check whether the data matches one of the limited numbers of valid entries. **File lookup checks:** check whether the data matches any of the limited entries listed in a file.                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Input data must be either `1`, `2` or `3`.                                                                                          |
| **Batch header check**           | Concerned with batch processing. **Batch processing:** A method computers use to periodically compute high-volume, repetitive data jobs. Certain data processing tasks, such as backups, filtering, and sorting, can be compute-intensive and inefficient to run on individual data transactions. Instead, data systems process such tasks in batches, often in off-peak times when computing resources are more commonly available. The total number of records in a batch should be calculated by the computer and compared with the figure on the batch header. The control totals and hash totals are also calculated and compared. | —                                                                                                                                   |


# Data Verification

| Verification Method / Error   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Example / Notes                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Transcription Error**       | A transcription error is a specific type of data entry error that is commonly made by human operators or by optical character recognition programs (OCR). **Human transcription errors:** Typographical mistakes, e.g. putting fingers in the wrong place during touch typing. **Electronic transcription errors:** A scan of printed text is compromised or in an unusual font, e.g. the paper is crumpled, the ink is smudged when wet, the OCR may have a transcription error when reading. | `Gtegory` instead of `Gregory`, `34rd of August` instead of `23rd August`, `Jishua` instead of `Joshua`. |
| **Transposition Error**       | Occurs when characters are swapped accidentally. Mostly due to errors while touch typing.                                                                                                                                                                                                                                                                                                                                                                                                      | `Gergory` instead of `Gregory`, `23rd of Auguts` instead of `23rd of August`.                            |
| **Proof reading**             | Watch the screen while typing. If the entry is occurring in data capture forms, databases or subscription forms, the code of the forms or the database administrator should **use input masks or validation rules**. **Input mask:** A pre-defined data entry template that specifies the valid format of data entered into a field.                                                                                                                                                           | Phone numbers, dates.                                                                                    |
| **Visual check**              | Checking for errors by comparing entered data with the original document.                                                                                                                                                                                                                                                                                                                                                                                                                      | —                                                                                                        |
| **Double entry verification** | Enter the same data twice.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | —                                                                                                        |
| **Check digits**              | Check digits can be used to verify that entered numerical data is correct.                                                                                                                                                                                                                                                                                                                                                                                                                     | —                                                                                                        |
| **Control total**             | Any predefined value used to verify data accuracy and completeness during processing.                                                                                                                                                                                                                                                                                                                                                                                                          | —                                                                                                        |
| **Batch totals**              | Batch total is a specific type of control total. Ensures that the number of fields in a batch is correct. Before the information on the documents is entered, the user counts **how many documents there are**. This is the **batch total**. As the data is entered, the computer keeps track of how many documents are entered. The manually calculated total is then compared to the computer-generated total.                                                                               | —                                                                                                        |
| **Hash total**                | A value that checks whether data has been altered. A hash total is a numerical sum of one or more fields in a file, including data not normally used in calculations, such as account number. The original hash total is stored, and if needed, the data is recalculated and compared with the original hash. If data are lost or changed, a mismatch signals an error.                                                                                                                        | Account numbers may be included even though they are not normally used in calculations.                  |

# Programme Errors

| Type of Error | Description | Example |
|---|---|---|
| **Syntax errors** | An error that occurs when a command does not follow the expected syntax of a language. | `IF` without `THEN` |
| **Runtime errors** | An error that only occurs when the programme is running and is difficult to foresee before a programme is compiled and run. | Divide by zero |
| **Logical errors** | An error that causes the programme to output an incorrect answer when the programmer makes a mistake in their logic for some parts of the programme. | `count = count - 1` should be `count = count + 1` |
